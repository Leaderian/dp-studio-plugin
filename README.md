# 리더리안 상세페이지 스튜디오 (수강생 전용 Claude 플러그인)

강의 수강생이 Claude 데스크톱 앱에서 지식상품 상세페이지를 대화로 만들 수 있게 해 주는 플러그인입니다.
**수강생 명단에 등록된 구글 계정으로만** 쓸 수 있습니다.

## 설치 (처음 한 번, 약 5분)

1. **Claude 데스크톱 앱**(Pro 이상)을 열고 왼쪽에서 **Code** 탭으로 갑니다.
2. 입력창에 아래 명령을 그대로 붙여 넣고 Enter 를 누릅니다. **마켓플레이스 추가** 창이 뜨면 **동기화**를 누릅니다.
   ```
   /plugin marketplace add https://github.com/Leaderian/dp-studio-plugin
   ```
3. 목록에서 **상세페이지 스튜디오**의 **+**(설치)를 누릅니다.
4. 바탕화면에 **상세페이지** 폴더를 만들고, Code 탭에서 그 폴더를 엽니다.
5. (처음 한 번만) 입력창에 `/mcp` 를 입력하고 **plugin:leaderian:dp** → **Authenticate(인증)** 를 누릅니다.
   브라우저가 열리면 **구글 로그인 → 이용 약관 동의**를 하고, "인증 완료" 화면이 나오면 앱으로 돌아옵니다.
6. 입력창에 `/leaderian:detailpage 만들고 싶은 상품 주제` 를 입력합니다.

자세한 그림 안내는 리더리안이 나눠 드린 설치방법 안내서를 봐 주세요.
